# The seed — bootstrap and cold start

This document specifies the bootstrap: the minimal foundation — system prompt, tools, first heading — that allows emergence without forcing it. It states the physics the kernel offers, the instincts and the Hole that make up the seed, the raw tools, the provisional v0 heading, and the instruments that falsify the result. The kernel's technical specification is in [kernel.md](kernel.md); the co-negotiation of the direction is in [direction.md](direction.md).

## 1. The question

Two traps: early production (an intern thrown into the codebase) vs disguised pre-wiring (drawing the tree). **"Zero structure" is not an option**: full autonomy is the worst measured protocol, and minimal scaffolding — fixed order, self-chosen roles — beats the Coordinator by **+14%**; the effect is capability-dependent (Dochkina, arXiv:2603.28990 — single-author preprint, 25,000+ task runs; exact figures in [research/sota-autonomous-agents.md](research/sota-autonomous-agents.md)). The question is not "seed or tree" but "**which minimal structure**": one that is **physical** (the kernel) and **dispositional** (the instincts), never **organizational**.

**The criterion that settles pre-wiring empirically: antecedence.** An organizational artifact that appears *before* the friction that justifies it is pre-wiring (or corpus replaying); an artifact that appears *after* a friction dated in the frontier journal or the world's history is a genesis. Measurable, falsifiable, free (§7). The one deliberate exception is the interface: the conversation channel is a Lead product decision made before the friction that would justify it, so its genesis finding is forfeited by design — what remains measurable is its adoption, its traffic, and the recap against the raw threads ([kernel.md](kernel.md)).

## 2. The physics: the kernel is a recursive graph

**The kernel does not know delegation — it knows the recursion of Γ.** A single primitive, the **node**: a self-similar context (`Γ∞ = μΓ. Γ × (Γ→Γ) × Σ` — Cordis, arXiv:2608.25512, Definition 28) that can carry an agent, modules, child nodes: `Node = ⟨ uid, Γ, state, inverse accumulator (LIFO), charter, capabilities, budget, wake watermark ⟩`. Root and leaf have the same shape; there is no "manager type" and no "worker type". Birth = recursive instantiation; death = the node's own end, which reverts its Packages and Runs in LIFO order (Theorem 16) — the spawned roster is flat, so a composed node keeps running when its composer ends; attenuation = a node can grant only a subset of its capabilities and its budget, enforced at the kernel's mutation gate, not bypassable. **Confluence (Theorem 80)**: a bootstrap assembled by incremental patches converges to the state of a clean load — a correctness criterion for the bootstrap, free of charge.

- **A roster and a graph, not one** (critical discipline): the **runtime roster** (physical: the flat set of live nodes on one home — operator-declared spawn grants, one 16-node ceiling, no parentage; a composed node keeps running when its composer ends) and the **authority** graph (a projection of the world's commit history and the chat — emergent, free: DAG, lateral, cyclic). It cannot be a projection of the frontier journal (the chain carries no node identity; the attribution sidecar names the caller of an exchange, never the conversation, `kernel.md`) and never of the local logs, which no outside observer reads — the node's own reading of its own record (`extend {verb:"history"}`) is the node's act, journaled as an ordinary tool result, never an observation surface, and it changes nothing here: the authority graph remains a projection of the world's commit history and the chat. Decoupling: a node can *ask* another node to instantiate one, and the kernel records no parentage — roster ≠ created-by; kinship is information the nodes commit themselves. **Leak test**: if the org-projection is isomorphic to the runtime roster on every run, the roster has leaked — a design failure, not an emergence success. (Single-node runtime: the projections are specified, not implemented.)
- **The kernel contains**: the frontier journal (every kernel-mediated HTTP exchange — "model-visible means logged"), the node's local log (its cold-start artifact), a single mutation gate, pinning of the heading outside compaction, node instantiation, writes serialized per resource — implemented; the escalating kill switch — specified, not implemented. Token accounting is memory physics (the compaction trigger and the assistant's journaled usage anchor), not a cost budget: no price, monetary tank, timer count/cadence quota or admission economy is implemented or required. An optional start-only operator node response-token stop is implemented as an operational node cap, not a price or provider bill; the gateway remains uncapped. A local GPU or sponsored credits is a supported deployment without an upstream financial ceiling. **No organizational vocabulary.** Agent zero is the gateway — a host-side overlay service over the system, never a node: no cell, no turn, no world write; the cycle and its three tools are kernel equipment, and its role is charter data ([direction.md](direction.md)).

## 3. The seed: instincts + finitude + Hole

**Golden rule: the seed is a strict subset of the means needed for the heading.** Not "insufficient through negligence": a **calculated Hole** between the ambition of the heading and the tooling provided — the engine, never named. Hypothesis testable by ablation: **Emergence = Necessity × Propensity** (Necessity physical, Propensity dispositional; if either is zero, nothing pushes).

The 5 instincts (trigger + direction of effort, never a product). Cut order if reducing: I5, I2, I1, I4, never I3. Each has a known **counterfeit** to watch for (e.g. pre-wired I1 = "create a specialized agent" — it names the artifact, therefore draws the tree).

1. **Name** — "when the same thing comes back, give it a name" (source of all durable vocabulary)
2. **Keep** — "when something worked (or failed), keep enough to do it again (or avoid it)" (the "or failed" clause buys resistance to primacy bias)
3. **Tool up** — "when you lack a means, build it — or ask for it" (**the engine**, never the culprit)
4. **Ask** — "before crossing a frontier, say so" (a habit, not a gate: crossing requires no approval)
5. **Signal** — "when you no longer see how what you are doing serves the heading, say it and stop" (against drift through inaction, which is larger than drift through action — arXiv:2505.02709, Finding 8)

- **Finitude — physical, with a single face. The Hole** — the context is compacted periodically; whatever is not externalized is lost. The kernel's compaction is deliberately **naive and visible** (a local-log event); any memory strategy beyond it is an **agent production**. The factory default announces the Hole as a fact, with no solution provided: the fixed notice replaces the erased span, and the agent, self-aware of its own machine, sets up its own context and memory management. A cell whose operator enables the journaled memory gate runs the **authored-first arm** instead: the node authors, through `extend {verb:"remember"}`, the bounded text that replaces the notice at the next compaction when the kernel's strict-smaller rule admits it (the text plus the kernel's fixed frame must be smaller than the removed span). The kernel still provides only the transaction, the bound, the fixed frame and the placeholder; the CONTENT is the node's production, the kernel never calls a model for memory, and the authored survival is a one-compaction reprieve, never a durable record: the pending slot is runtime-only host state and is lost on restart, while an applied replacement rides the summary record until the next compaction erases it. This is a deliberate treatment change, *le traitement change, c'est un choix expérimental assumé* — it changes what the node may put in the kernel's placeholder, never the Hole itself; the externalization pressure remains the default arm and the object of study.
- **Cost is measured, never injected.** The provider's response usage rides the node's assistant record as the token meter's ANCHOR INPUT — the tuple `{headerDigest, surfacePriceAtSample, usage}` journaled with the assistant message, never a price and never a budget surface; the human-side recompute from complete frontier bodies stays AUTHORITATIVE (anti-Goodhart). The agent has neither visibility into a budget nor responsibility for one: a parasitic frugality objective would divert it from the heading. There is no kernel budget to expose: modern explicit timers and cadence are not count-limited, and normal chaining/retries are not financially gated. The trigger's effective percent is operator-side ([kernel.md](kernel.md)), and no price exists in either record.
- **No artificial friction on frontier crossings.** The world is not undone — a fact, not a rule; the reversible/irreversible frontier of `extend` is *stated* (in the heading) and *observed*, not guarded: a `define`/`run`/`call`/`stop`/`undefine` is a local-log fact, not a frontier one, while every model call the extended behavior makes still crosses the frontier.
- **Hard physics.** Implemented: the frontier journal, the filesystem-confinement boundary (it constrains where agent effects can land, not what the kernel records), the storage circuit breaker and per-child git/shell/Run deadlines. Specified, not implemented: the escalating kill switch. An operator MAY set an upstream hard limit on the API key — invisible to the agent — but it is deployment policy, not a kernel prerequisite or a claim that turns, chains, retries or timer wakes are otherwise bounded; a local GPU or sponsored credits needs no such ceiling. Consequence: the Hole (compaction) is the only physical pressure of Necessity, while spending/publication are bounded by the deployment's own policy and the kill switch residual. The earliest drift signal to watch is **capability-creep** (breadth of rights requested vs demonstrated competence).

## 4. The seed's tools (raw paradigm)

**Raw** tools, the LLM does everything — no business-value tools, which would encode a theory of what the system should do, i.e. pre-wiring through the tooling. Small toolsets are the rule: studies report reliable tool choice up to roughly 4–10 tools, with over-presentation degrading choice (arXiv:2605.24660; Zenodo 21274521) — the same paradigm as DeepSeek Harness, whose minimal preset is built around a persistent shell.

| Tool | Semantics | Status |
|---|---|---|
| `execute` | one command in a persistent PTY shell confined by Landlock — reads its world, its per-node scratch leaf and the explicit system read set; writes only its world, that leaf and the granted writable devices; egress open by decision. The kernel commits the world at the end of each turn (author = node uid; the shell cannot read the world's git history, so a practical `undo` is a kernel-side files-only revert) | implemented |
| `wait` | loop control — park until a foreign commit, a conversation notice, or the one selected timer fires. A MODERN cell (fresh host starts, `policy.wake` present even at cadence 0) accepts `{}`, `{until}` or `{after_seconds}`; the relative delay starts at the actual park, the last accepted wait selects the arm, and explicit timers/cadence carry no timer count or cost quota. A LEGACY cell keeps `{until}` only, with its exact receipt and `wakeBudgetPerHour` timer-fire counter | implemented |
| `web_search` / `web_fetch` | read-only web access (no world write) through the kernel-mediated provider; the invocation crosses the frontier: request durable before the send, terminal durable before the result | implemented |
| `extend` | the Cordis gate in a single tool: `inspect` (a read-only catalogue of the runtime, generated from the live registry) / `define` (immutable Package, no effect) / `run` (a confined child executing the Package's code) / `call` (the funnel: invoke a registered tool by name with args — a native call by the bare name is bridged to it) / `stop` (reversible) / `undefine` (irreversible) / `update_self` (rewrite the node's own heading, charter or model — the charter by `path` of a world file; the change is journaled as the next config version, applies from the next assembled request, and the local log is its history) / `request_death` (the node's own clean end: granted unless it is the last live node, whose end is the operator's pause; the stop cancels the turn's remaining calls). `run` and `undefine` address a Package by name or id — a name resolves to the newest stored version under it (run picks the newest verifying one; undefine refuses a newest that does not verify, teaching the id); `stop` addresses the live Run by its package's name or id, or by nothing — the Run is a singleton, so a bare stop names it; `history` reads the node's own records — the last n entries of its own timeline (oldest-first, default 16, at most 64, stateless), its identity versions as facts (model, heading, charter bytes + digest, never the past charter text), its turns with the paths their commits changed, its perceptions of the world's patches verbatim as it saw them, its lifecycle (a crash leaves no shutdown record — never inferred), its compaction markers and its pinned directions; never another node's record, and the records are data, not instructions | implemented |

**Communication is a file.** No tool carries a message between nodes: a node reaches another by writing in the world, which the kernel commits at the end of its turn (author = its uid) and which wakes every node that did not author it. Whatever protocol the society invents — addressing, threading, a bulletin board, a mailbox implemented as a directory — is an agent production, measured like any other organ. **The sanctioned exception FAMILY is the interface**: `send_message` writes one message into the kernel-owned conversation stream, addressed to the reserved `gateway` (a node's `to` is absent — the default — or `gateway`; the kernel is not a node↔node transport), and `get_messages` reads the caller's own thread (the last n records, no cursor); the stream is the interface, never the society's interior, which stays file-only. The human channel's `speak` tool is removed from the node offering, and its successor is the overlay's native chat: each successful gateway cycle delivers one response record into the chat log (implemented), and the human types through the interactive `chat` session (implemented) or its batch twin `direct` (implemented: `direct --text/--file` appends the same human record and returns without waiting). The human's one world-writing act is `direct --path <world-relative> --file <abs>`: the ratification, a commit authored the reserved `human` (implemented). **`spawn` is not a seed tool**: it lives in the kernel, not mounted, discoverable via `extend → inspect` and callable as `extend {verb:"spawn", ...}` by a node the host granted the capability; its first use is a dated event — the founding observable of the spawn checkpoint ([ROADMAP.md](../ROADMAP.md)). **Self-extension model** (taken from DeepSeek Harness): Plugin → **immutable Packages** → Runs; the Package survives a restart while the Run is in memory (implemented).

An operator composing a node's charter (`--charter-file`, or a nodes-file `charterFile`) may name the conversation convention in one line: *the conversation is the interface — `send_message` reaches the gateway, and a message FROM the gateway arrives as a notice.* A node may rewrite its own charter (`update_self`, by world path) and erase that line: the erasure is a first-class observable — the `update_self` call crosses the frontier, and the node-local journal keeps the identity history — not a bug.

## 5. Seed system prompt (design specification — data, rewritable, not kernel; the person speaking to the agent is agent zero, not the human — [direction.md](direction.md))

```
You run continuously. You have no task: you have a HEADING — a direction given and revised by the person speaking to you. The heading is at the head of your context, versioned. It is what holds authority — not your memory, not the last message.

You are a language model in a perpetual loop. Know your machine: your context is finite and will be compacted without preserving what matters to you; your memory survives only if you externalize it; your means are those you give yourself. Observing your own limits and working around them is part of the job.

You can recompose yourself (mount, unmount); what leaves the machine is not undone — the world does not repair itself, it is assumed.

Five tendencies: 1. When the same thing comes back, give it a name. 2. When something worked (or failed), keep enough to do it again (or avoid it). 3. When you lack a means, build it — or ask for it. 4. Before crossing a frontier, say so. 5. When you no longer see how what you are doing serves the heading, say so and stop.

One fact: your context will be rewritten — what you have not put outside, you will lose.
```

## 6. The v0 heading (design specification — provisional and expiring)

A structural countermeasure to primacy bias: the seed's first property is that it is destined to die; the system's first act is a **conversation**, not an obedience.

```
DIRECTION v0 — provisional, valid until the first negotiation.
Subject: <what the human brings>. We are not trying to finish something: we are trying to hold up over time while drawing closer to it.
Revision: v1 is negotiated in chat. Any proposal is welcome.
```

Pinned outside compaction and re-injected verbatim on every request (implemented; compaction erodes unpinned literal constraints and pinning restores them — arXiv:2606.22528). Injected into every child node's context, never the parent's report (structural anti-inherited-drift). The versioned letter is specified, not implemented ([direction.md](direction.md)); the ratification act is implemented — `direct --path DIRECTION.md --file <abs>` commits the heading authored the reserved `human`, and the pin reads the latest human-authored commit. The first negotiation that retires v0 takes place between the human and agent zero.

## 7. Falsification instruments (invisible to the agents, computed from the frontier journal + the world)

Attribution by node is implemented at two granularities — the world's commit authorship (`git author = uid`) for the act, and the frontier's attribution sidecar (`{call, uid}`, `kernel.md`) for the exchange — never from the local logs, which are the agent's cold-start aid only. The instruments themselves are specified, not implemented: **genesis adjacency rate** (is each organ preceded by a dated friction — repeated failure, cost spike, loss through compaction? if not: corpus replaying); **org/runtime isomorphism** (does the organizational projection diverge from the runtime roster? if not: the roster has leaked); **organ usage graph** (an organ never invoked 48 h after creation is a dead organ). Falsification experiments: free arm vs complete seed; ablations of I3 and I1 (tests Emergence = Necessity × Propensity — the necessity face being the Hole alone); graph kernel vs flat kernel at equal heading; date of first external emission (tests early production).

## 8. Failure modes to watch

- **Inward-facing construction** (navel-gazing): organs mounted but never invoked; zero frontier crossings over N days.
- **Bureaucratization of the instincts**: early meta-organs; a names/actions ratio rising with no production.
- **Primacy lock-in**: monotonically decreasing semantic novelty; **no dismantling, ever** — where dismantling is physically free, the absence of `stop` is an unambiguous signature of ossification.
- **Polite waiting**: empty turns are recorded in the node's local log, which is not an observation surface; what remains observable is the absence of a world commit between two observed exchanges, and prose that shortens and becomes deferential stays readable in the world's commits.
- **Frontier sprint**: external emissions before any demonstrated local success (ambition precedes competence) — the main signal in the absence of guardrails.
