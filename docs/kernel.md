# Kernel — technical specification

The runtime's specification: the two records, the world and node driver, the context assembler, the sandbox, the credential store, and the target designs owned here. Concepts: [vision.md](vision.md), [seed.md](seed.md), [direction.md](direction.md). Progress: [ROADMAP.md](../ROADMAP.md). Concepts→code: [architecture.md](architecture.md). Status vocabulary: **implemented** / **specified, not implemented** / **rejected**.

## Runtime behavior

- **Async, event-native, non-blocking.** No "waiting for the human" state: raising a problem is a world write, the answer arrives as a change the node wakes on (dsh's `ask_user_question` blocks a turn on the human — rejected counter-model).
- **Free loop, explicit unbounded wait.** No wake budget (dsh's `maxConsecutiveWakes` — rejected: observation over prevention). Physical bounds: upstream budget ceiling, kill switch, frontier journal and its gate, mutation gate, confinement boundary.
- **Re-alignment without interruption.** A ratified heading propagates to every node's next turn as a verbatim pinned reference; the propagation delay is the relaxation measure (`direction.md` §2–§3); flow-down travels through charters and delegation.
- **Mechanism and policy.** The kernel is the physics (the two records and their gates, watcher, commit-per-turn, sandbox); loop, context and compaction policies are phenotype — trusted kernel-side behavior, replaceable Packages through `extend` (**specified, not implemented**). Policy changes are local-log facts; the frontier records HTTP exchanges only. **Agent zero** is the root custody node under the same physics; its equipment (human channel, heading drafting, raw-frontier reading) is data, not kernel (**specified, not implemented**, `direction.md` §1).

## Stack

TypeScript strict mode (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`), Node 24, Vitest; exactly two runtime dependencies (`AGENTS.md`). Cordis is **specified, not implemented**: a pinned cordis release, core only, installed by `extend`; not a runtime dependency. `@cordisjs/plugin-loader`/HMR: **rejected** (documented races and pending-gate hangs, cordis #194/#231; Node internals + native addon). Design basis: on average 94% of compilation errors in LLM-generated TypeScript are type errors (arXiv:2504.09246, the paper's own measurement) — the invariants here are what a type system makes unavoidable; the reference corpus (Cordis, dsh) is TS; 0/11 production harnesses import an agentic framework in the agent runtime (arXiv:2609.00006, Observation 13.2, static-analysis caveat); SWE-PolyBench (arXiv:2504.08703) is the repo-level reference. Fallback: Python 3.14 + anyio, hot-reload = clean shutdown + remount, never `importlib.reload` (python.org: extension modules "may fail in arbitrary ways" on reload; no transactional hot-reload precedent found in Python).

## Cell-home layout

```
cell-home/
├── world/                      # the worktree — the only communication channel
├── world.git/                  # the world's git dir, kernel-owned, outside the worktree
├── tmp/<uid>/                  # per-node shell scratch leaf (0700, kernel-created)
├── frontier/
│   ├── journal.v0.jsonl.zstd   # THE TRUTH — append-only, hash-chained, one total order
│   ├── journal.v0.head         # chain checkpoint {first_hash, last_hash, count, ts}
│   ├── journal.v0.lock         # flock sidecar (stable inode)
│   └── journal.v0.owner        # durable owner record {pid, startedAt, token}
├── nodes/<uid>/
│   ├── log.v0.jsonl.zstd       # the node's cold-start log — observers never read it
│   ├── log.v0.head / .lock / .owner
│   └── snapshots/<seq>.json    # projection checkpoints (disposable, retention 2)
├── providers.json              # kernel-side credential store — plaintext at rest
├── blobs/<2 hex>/<sha256>      # content-addressed store, shared by both layouts
└── index.sqlite                # disposable index — specified, not implemented
```

The frontier journal is the truth: one chain per cell home, every kernel-mediated HTTP exchange durable before the effect, no knowledge of nodes, turns or Packages. The node's local log is its cold-start artifact; nothing observational is derived from it. The world's git history is the second observation surface. They join through both halves: every `http/request` carries the kernel-stamped, best-effort `world_head` (`null` when unreadable — an exchange on the world's timeline, never attributed to a node); every `turn/end` carries its turn's commit hash (commit-granular, at recorded turn boundaries).

## Legacy-world migration

A world created before the external git dir is refused at open (the failed pair/trust check; no auto-migration) — a bare `mv` would carry a poisoned config/hooks/symlink/hardlink layout into the kernel's trust zone. Recipe:

1. Record the pre-migration head: `git --git-dir=world/.git rev-parse HEAD`.
2. `mv world/.git world.git`.
3. Sanitize: remove `config.worktree`, `info/grafts`, `shallow`, `objects/info/alternates`, `commondir`; `rm -rf hooks`.
4. Materialize every symlink (`cp -a`, repeat until `find -type l` is empty).
5. Replace multi-linked files (`find -links +1` — hardlinked HEAD/refs survive plain mv).
6. Rewrite config to the allowlisted keys: `repositoryformatversion` (keep `1` for sha-256), `filemode`, `bare=false`, `logallrefupdates`, `untrackedCache`, `extensions.objectFormat`.
7. Re-seed hooks via `git init` (recreates the 14 `*.sample` files).
8. Record `core.worktree` (absolute worktree path).
9. Postcondition: HEAD equality with step 1.

An agent-created `<world>/.git` is ignored at open and never staged (refusing it would hand the shell a permanent boot-denial via `mkdir .git`).

## The two records

**Envelope (frozen with v0):** `{v, type, seq, time, prev_hash, hash, ignorable?, data}`; contiguous `seq`; epoch-ms `time` from the driver-injected `now()`; genesis `prev_hash` = 64 zeros; `hash = SHA-256(prev_hash ‖ RFC8785(v, type, seq, time, ignorable, data))`. A reader that does not know an event type refuses to rebuild unless it carries `ignorable` (a local-log mark for skippable events, e.g. the empty turn's closer; every frontier event is required). RFC 8785 (JCS) fixes one deterministic byte representation; lossless-unserializable values (NaN, Infinity, lone surrogates) are errors; the canonicalization is data-only at a trusted boundary — no accessor or `toJSON` hook is ever called, a callable one is refused.

**Storage.** Independent checksummed zstd frames, one per durable batch, split below `MAX_DECOMPRESSED_BATCH_BYTES = 64 MiB`; the frame magic `28 B5 2F FD` discriminates a torn tail (partial write, repairable) from interior corruption (never truncated). A fixed 200 ms write-behind window opens on the first event of a burst (no debounce), one `fsync` per flush. The flush barrier splits by artifact: frontier `begin` durable and read-back verified before the send, `complete` before the caller proceeds; local turn envelopes and gate artifact writes flush per event (`turn/start` before the handler acts, `turn/end` before the loop unwinds — it carries the commit hash). A failed write rolls back to the durable watermark; two consecutive failures, or a failed rollback, poison the writer. One writer per stream: a stable `flock` sidecar serializes lifecycle transitions; the exclusive right is a durable `{pid, startedAt, token}` record written by a short-lived helper under the guard (a crashed helper releases the lock by itself, a dead owner's record is reclaimed, release is token-bound). Requires util-linux `flock` and `/proc`; not a shared-disk (NFS/multi-host) protocol. Directory entries are proven durable (each level fsynced from the trusted root down) before a batch or blob reference counts as durable; a head failure is a diagnostic, never a poisoned log. Crash repair is the reader's job — durable events stay, a torn fragment is discarded — and at open the frontier gives every `http/request` without a terminal exactly one `http/incomplete`: an open call is a fact, never a guess. A payload whose root matches the reserved reference shape is refused at append.

**Claim-check.** A local payload at or beyond `CLAIM_CHECK_THRESHOLD = 16 KiB` canonical UTF-8 becomes a content-addressed blob reference; at or beyond `MAX_BLOB_BYTES = 4 MiB` the blob holds a prefix, the reference carries `truncated: true` plus the original size — never silent. No frontier body is ever claim-check-truncated: the blob holds exactly the captured bytes, a bounded capture is recorded whole, flagged `complete: false`. `FRONTIER_MAX_BODY_BYTES = 32 MiB` fail-closes *requests* at `begin` (nothing is sent); *responses* are bounded by the transport's `maxBytes` and journaled whole. All constants frozen with v0, comparisons inclusive. A verified read proves digest and exact byte length; a raw read returns the reference unchanged.

**Frontier honesty.** The journaled request set is a superset of the sent set; no terminal asserts that bytes reached the socket. Bodies are recorded as captured (post-`content-encoding` decoding); only allowlisted headers are recorded; a credential's *id* is journaled, never its value; redirects are never followed. Usage, model and cost are projections recomputed human-side from complete bodies: the three provider dialects (Anthropic `cache_read/creation_input_tokens`, OpenAI-compat `prompt_tokens_details.cached_tokens`, DeepSeek `prompt_cache_hit/miss_tokens`) are normalized there, never in the record; no price exists in either record.

**Replay ≠ re-execution.** A replay makes no model or tool call: it reads the local log and the world's history; the exact wire bytes live in the frontier journal. Event time is virtualized (injected `now()`), making the local fold deterministically replayable. No compaction of either canonical stream (rollover: specified, not implemented). Snapshots and the SQLite index (**specified, not implemented**: WAL, `synchronous=NORMAL`, single writer, `busy_timeout`, stale `user_version` refused, `PRIMARY KEY (seq)` on the frontier stream) are disposable; boot today is the full-history fold plus the frontier's full read and orphan scan.

## Context assembler and pinning

Perception is a diff, not a queue — the world's diff since the node's last wake plus its durable state; what enters the context and what is retained is policy. The assembler is pure (no I/O, records nothing); its plan is never journaled — the exact bytes it produced are the frontier's fact. The `ContextFold` consumes only chain-verified local events and proves the local sequencing (assistant message before its calls, artifact receipts, compaction group balance); a failed fold is poisoned and re-folds from scratch. Configuration and parameters are validated against the one shared provider-parameter contract before acceptance; no silent migration; a forged claim is refused on fold.

**Prefix layout (cache-aware, byte-stable):** `[0]` tools (frozen, fixed order, canonical JSON) → `[1]` charter → `[2]` pinned heading → append-only message surface (breakpoint B) → runtime queue, never before B. No timestamp, session id or counter in blocks 0–2: per-request values there are the documented cache invalidators (Anthropic, Moonshot); a heading change invalidates the cache once, and the `cache_creation` spike is a free observable of the version change. A shared tool offering across working nodes is a host/seed obligation, not a kernel-enforced invariant (the assembler hashes the config it is given); capability attenuation applies at the mutation gate, at execution time, not to the offering. Compaction and pinning are one mechanism: compaction ranges over surface positions excluding node 0 (`SurfaceOp = 'append' | {op:'replace', positions}`, `sourceEventSeqs` mandatory and verified; a replace covering node 0 must be a `system/message` on exactly that node) — the dsh protocol, this project's own naive, visible, rare policy; the log stays intact.

**Provider adapter.** One canonical non-streaming wire; bounded retries (network/timeout or 408/429/500/502/503/504) reuse the same body bytes and frontier `group` with an incremented `attempt`. A pre-response stop leaves a `status: null` cancelled terminal; a status-known stalled body keeps its status (`timeout` retryable, `body-limit` terminal); gate cancellation is checked first and wins. Model-visible bounds keep the raw fact and append a fixed truncation notice naming the capture's own facts. Never an external proxy in the path — documented LiteLLM issues (#32112, #30371) show a proxy altering request bodies.

## World, time, and the node driver

- **No kernel message transport.** No inbox, no `send`/`deliver`, no hub, no `message/*` events: nodes communicate by writing files in the world, through the same persistent terminal session. Whatever the society needs — addressing, threading, a mailbox — it builds in files, and it is measured as an organ (a kernel transport would fix the shape of communication before any friction justifies it). `speak` — the human channel, owned by agent zero (**specified, not implemented**, `direction.md` §1) — is the single sanctioned exception (the human has no file to read); human input enters the world as a commit authored by the human.
- **Wake-on-change.** The kernel watches the world's git HEAD, not the filesystem: each wake is pinned to an opening range (watermark → HEAD at turn open), so perception is taken at a commit boundary, never mid-write; commits landing between turns are covered by the next wake's range (a commit-boundary guarantee, not a no-event-missed claim). A node wakes when HEAD carries a commit it did not author; its own commits never wake it; wakes coalesce. A static world spends no tokens.
- **The turn ritual.** A turn opens on the assembled context and ends with the kernel committing the world (git author = the node's uid) and appending `turn/end` with the commit hash. A failed turn is a local-log fact, not a death; a crash is closed by synthetic closers at resume, leftover writes committed under the node's authorship — an effect is never left unattributed; only a bounded fixed failure label reaches the local log. An interrupted turn is reconciled, not guessed: the candidate commit must carry the node's uid and the exact subject `turn N`, the bounded walk (4096) is refused rather than truncated, ambiguity fails typed, with no match the whole working tree becomes the node's recovery commit (a peer's dirty files are swept in — attribution is commit-granular: the git layer says who moved the world when, not who wrote every line; per-node worktrees are the research direction, not a current mechanism).
- **The commit is plumbing.** The kernel never runs `git commit` — it writes the repository-wide `.git/COMMIT_EDITMSG`, so concurrent commits race on one file (git aborts: "Aborting commit due to empty commit message."). Instead: `add --all` → `write-tree` → `commit-tree` → compare-and-swap ref update, bounded retry (4 attempts at 25/50/75 ms) on a held lock or lost CAS, so the recorded hash is always this call's. The git environment is hardened (`GIT_DIR`/`GIT_CONFIG_*` stripped, system/global config, replace refs and lazy fetch neutralized) and five trust layers keep the kernel's git inputs kernel-owned: a `-z` config scan refusing non-git-dir origins and execution-capable or history-rewriting keys; a metadata battery (no `config.worktree`/alternates/grafts/shallow, `*.sample` hooks only, no symlinks or multiply-linked non-directories under the git dir); the pair check (absolute `core.worktree` and git dir realpath-equal); per-call defense-in-depth overrides; the external git dir verified at every open. Hard guards refuse a world at `$HOME`, `/`, or a symlink resolving to one — an unguarded `git add -A` over a trusted home filled >200 GB of disk (Codex incident #19588), the incident this guard exists for. A nested repository inside the world is never committed (gitlink stripped); no component owns world garbage collection. `core.untrackedCache = true`; the design does not watch the filesystem, so fsmonitor is unused.

## Sandbox and shell

Only the `execute` shell is confined, and confinement fails closed: a sandbox that cannot be built or probed makes every `execute` close as `spawn-failed`. Reference platform: Ubuntu 24.04 (HWE), kernel 7.0 — Landlock ABI 8, unprivileged.

**Containment: Landlock**, via a vendored C launcher (`native/es-landlock/`, modeled on the kernel's `samples/landlock/sandboxer.c`) that self-restricts *before* an in-place `execve("/bin/bash")` — never an intermediate script — preserving pid, session and controlling tty. A restricted thread can never widen its policy; restrictions are inherited by every child. Rights are masked per target type (each grant `fstat`ed, only its applicable rights requested; the handled set runs through `TRUNCATE`, minus `IOCTL_DEV`). The binary is git-ignored, built by `npm run build:native` with the host `cc`, rebuilt by the vitest global setup when absent or stale. Bubblewrap is **rejected**: it needs user namespaces — Ubuntu ≥ 23.10 restricts unprivileged userns via AppArmor (default-on since 24.04; the default profile still allows unconfined userns) and bubblewrap is userns-only since its setuid mode was removed upstream — where Landlock needs no namespace dependency and no root. The launcher also arms `PR_SET_PDEATHSIG` (`SIGKILL`) immediately before the in-place `execve`, with one post-`prctl` parent re-check: a confined program never outlives the process that spawned it (the setting survives `execve`; the residual is a spawner SIGKILL'd inside the fork→launcher-entry window — never assertable).

**Allowlist (kernel-side).** World and per-node scratch leaf writable; merged-usr directories read+execute; a narrow `/etc` file list plus `/etc/ssl/certs` and `/proc` read; five device files granted individually; `/tmp`, `/home`, `/var`, the project checkout and `<home>` itself never granted. The sandbox owns `HOME=<world>`, `TMPDIR=<scratch>`, `HISTFILE=/dev/null`. A functional probe runs at first execute (not at startup), in the short-lived launcher process: write/read-back/remove in each writable dir, an exact-`EACCES` read of a denied path, the paired `/proc/<ppid>` check (stat readable, environ denied). Any failure exits **125** with one `es-landlock:` stderr line and never runs the command; `spawn-failed` is settled only under the documented conjunction — sandbox active, no start marker, exit 125, retained spawn-capture bytes carrying that signature (a child can forge stderr; an unknown exit code deliberately fails it). `sandboxStatus()` reports honestly — `{mode:'off'}` for `--no-sandbox` (the loud opt-out), `null` before a probe, `{mode:'landlock', abi, enforcement}` with `full` = ABI ≥ 6, `partial` = ABI 3–5 — deliberately not journaled. ABI floor 3 (`TRUNCATE`): below it, `open(O_TRUNC)` bypasses write mediation and the guarantee is void. `SCOPE_SIGNAL` and `SCOPE_ABSTRACT_UNIX_SOCKET` are enabled at ABI ≥ 6.

**Scope honesty (current).** The guarantee is scoped to filesystem *content*: `providers.json`, the frontier journal, local logs and host files outside the read set are unreadable and unwritable from the shell. It is not a claim about ambient authority: shell egress is open by design (no network rights handled at all), pathname UNIX sockets are unmediated at ABI 8 (no such right before `RESOLVE_UNIX`, ABI 9; UDP only in master, ABI 10; no raw-socket right at any ABI), and the io_uring `URING_CMD` surface currently bypasses `IOCTL_DEV` (documented LKML report, fix pending upstream). Metadata mutations, existence checks and `chdir` succeed without content access; `/proc/<pid>/{cmdline,stat,status}` stay world-readable under the default `hidepid=0` mount, so no secret may ever sit in argv (the provider key travels in memory only). `no_new_privs` kills setuid/file-capability elevation; `ping_group_range` defaults to `1 0` (denied). `/sys` is not granted (lscpu/lsblk need sysfs) and `/dev/ptmx` is not granted (no new PTYs). No rlimits or cgroups — availability is not part of the guarantee; a non-root kernel uid is assumed (DAC underpins the `/etc/shadow` class Landlock does not cover). With the kill switch absent, a stop is cooperative.

**Persistent PTY.** One `node-pty` session per node behind a narrow `TerminalRuntime` port (`run`/`dispose`, optional `sandboxStatus`). Nonce markers on a single physical line; typed statuses (`completed` | `stdin_read` | `timeout` | `session_exit` | `cancelled` | `spawn-failed`); one active write per node; bounded per-command capture, no scrollback; a timeout kills and respawns the session. A PTY merges stdout and stderr into one stream; the model-facing render is sanitized, the local artifact keeps the verbatim bounded capture. The stdin-read wait is the Linux x86-64 `/proc` proof (`CONFIG_HAVE_ARCH_TRACEHOOK`; the syscall table is x86-64's), bound to the pts path frozen at spawn — on other architectures the exact-match-only design degrades to a timeout, never a false positive. The PTY does not survive a kernel restart (a new process cannot inherit a master it does not own); shell state is ephemeral, what matters is externalized. Three deliberate divergences from dsh's `tool-bash-persistent`: a stdin-wedged session is reset before the next command, a capture overflow never kills the command, completion wins over a same-tick abort. The interactive `write` verb is **specified, not implemented**.

## Credential store and broker

A node may need third-party credentials; no secret may ever enter the world. The kernel-side store (`<home>/providers.json`, plaintext at rest, unreadable and unwritable from the confined shell; schema in [architecture.md](architecture.md)) is implemented. The full broker is **specified, not implemented**: the agent's environment carries an endpoint-bound *placeholder*, never the secret; the broker substitutes the real credential on the wire only for the bound endpoint, refusing and recording a mismatch without leaking secret, placeholder or variable name — the pattern validated by [NVIDIA OpenShell](https://github.com/NVIDIA/OpenShell) (Apache 2.0: gateway-held providers, endpoint-bound placeholders, `credential_endpoint_mismatch` refusal; 1Password × OpenShell adds time-bound TTL custody). Plain environment injection is **rejected**: the real value would transit the agent's process, exfiltratable and invisible to the frontier. Every authenticated request is a frontier exchange; which providers a node may use is a capability attenuated at the gate.

## Kill switch and budget

**Specified, not implemented.** The kill switch is a bounded, escalating shutdown — first signal: graceful disposal of the tree with a 5-second backstop (a safety invariant, not a tunable); re-signal: immediate exit (the dsh `process-shutdown` pattern). The budget is a hard limit on the API key, set upstream, invisible to the agents; cost is a projection of complete frontier bodies computed on the human side only. An explicit `unhandledRejection` handler records and decides, never Node's default (`--unhandled-rejections=throw`) crash. Until the switch exists, a stop is cooperative.

## Model-selection criteria

The design is model-agnostic. A candidate must: (1) exist behind an OpenAI-compatible endpoint; (2) carry an acceptable license — DeepSeek V4.1 Flash ships open weights under MIT; GLM-5.3, GLM-5.3-Flash and Kimi K2.7 Code exist as verified vendor offerings; (3) report cache usage (Anthropic: `cache_control` breakpoints, max 4, 20-block lookback window; DeepSeek: `prompt_cache_hit/miss_tokens`; OpenAI-compat: `prompt_tokens_details.cached_tokens`; Z.ai: automatic caching on its OpenAI-compat endpoint, `cache_control` honored on its Anthropic-compat endpoint). The first cost lever is the cache-hit rate, hence the byte-stable prefix. Long-session capability claims (Kimi K2.7 Code: 12h+ sessions, 4000+ tool calls, ~30% fewer reasoning tokens) are vendor-reported, not independently evaluated. Prices, index scores and routing tables are volatile and deliberately absent.

## Skills (target design)

The skills system is **specified, not implemented**: specified `src/skills/<name>.ts` modules behind a specified `src/cli/skills.ts` command, no new dependencies. Eight skills, each a repo-verification or maintenance routine invoked by name: `verify-tests`, `verify-secrets`, `verify-sandbox`, `verify-frontier`, `update-docs`, `review-code`, `build-hermetic`, `format-code`. No skill exists in the tree; none may be assumed by docs or tooling.

## Patterns adopted from prior art

From [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (public, MIT): the journal protocol (append-only log as the only truth, checksummed zstd frames, bounded write-behind, torn-tail repair at the reader, `ignorable`-marked extensibility); the compaction protocol (`compaction/start|summary|end`, `SurfaceOp`, the node-0 guard); the process-shutdown backstop; the restricted-`ctx` facade for guest code behind a method allowlist; the persistent-PTY terminal. dsh analysis: [research/harness-deep-dive.md](research/harness-deep-dive.md). Event-sourcing prior art: VOLT (IETF Internet-Draft, work-in-progress, its own canonical JSON — not RFC 8785) for hash-chained traces; ESAA (replay as re-projection, arXiv:2602.23193); Statefold; ActiveGraph (content-addressed cache); Langfuse (immutable wide events). A PTY daemon owning sessions across restarts (the superset.sh terminal-daemon pattern) is **rejected** — known path, non-blocking.
