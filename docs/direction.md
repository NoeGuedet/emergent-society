# Chat & direction — the co-negotiation system

This document specifies how the direction is negotiated, carried and revised: the physical roles, the artifact that holds the direction, the act that makes a version authoritative, and the channel that carries it. Current state: the kernel pins a heading outside compaction and re-injects it verbatim on every request, and the pinned heading is the world's `DIRECTION.md` at the latest human-authored commit; the human ratifies a version with `direct --path DIRECTION.md --file <abs-path>`, one world commit authored the reserved `human` (a node's own commit of the file is a draft). The human↔overlay chat is the native medium: the chat log (`<home>/chat.v0.jsonl`, kernel-owned) carries both sides' records, written by the interactive `chat` session or its batch twin `direct --text/--file`, and the overlay — agent zero, a host-side digest service, never a node — digests it in its own cycle and delivers its prose as the chat response. The rich versioned letter, the ratification event beyond the pin, and the chat co-negotiation's measurement are specified, not implemented; agent zero's raw-frontier reading and the versioned proposal (heading + proxy + letter) remain specified, while proposing plain heading text in a chat response is the implemented convention. The technical realization belongs to [kernel.md](kernel.md); the seed-side consequences to [seed.md](seed.md).

## 1. Three physical roles, no mixing

- **The human** — the source. The idea, the thinking, the goal come from them. They speak only to agent zero: the chat log is the medium, and the conversation's per-participant thread filter plus the kernel-owned chat log keep the society from reading the human's words directly.
- **Agent zero** — **translator co-orchestrator**, implemented as the gateway overlay (`src/overlay/`): a host-side, single-tenant digest service, never a node. Each cycle digests the chat window and the conversation's gateway thread; on a successful cycle it delivers exactly one chat record (its final prose). Its three tools read the COMMITTED world (`read_world`, `world_log`) and send a message (`send_message`). It translates in both directions — human intent → system heading, system state → human language — and makes governance possible without governing on its own initiative. Reading the raw frontier journal and the projections is specified, not implemented in v1: the overlay holds no write capability of any kind, its read footprint is operator-visible (each read rides a frontier exchange), and it reads raw facts, never metrics — the sensors remain the human's instrument, otherwise they would leak into its heading drafts. It is never the only window: the human keeps direct access to the same raw surfaces (`chat`, the world's git, `status`), and agent zero's reports are verifiable against the raw evidence ("explain this spike" — audit by an agent independent of the population being audited).
- **The first node** (and all those after it) — standard nodes of the recursive graph, receiving the pinned heading exactly like any future node. Agent zero exists precisely so that the first node is not special.

**The human channel** is the native chat: the human's records and the overlay's responses interleave in `<home>/chat.v0.jsonl`, kernel-owned and outside the world. The interactive `chat` session and its batch twin (`direct --text/--file`) are the human's writing surface; a human record's arrival triggers the overlay's cycle through the `ChatWatcher`, and the overlay's own response records never re-trigger it (the actor filter). The node offering carries no `speak` verb — the verb is gone entirely. Between nodes there is no transport at all: a node is heard by **writing in the world**, which the kernel commits at the end of its turn with the node's uid as author, and which wakes every node that did not author it. Everything a node writes toward its parent is an observable, diffable commit — escalations, reports and "I can no longer see the heading" (instincts I4/I5) are free data points of the experiment.

## 2. The direction object — a double artifact

Constraint Pinning protects *literal* constraints: compaction erodes them, and pinning restores compliance (Governance Decay, arXiv:2606.22528 — a single compaction step raises the pooled violation rate from 0% to ~30%; pinning restores 0% at <0.5% context overhead; the paper's own honest-failure case: an operator-impersonation rescind breaks naive pinning, 0%→17%, hardened 10%). A *rich and implicit* direction is not pinnable as is. Hence two linked forms, versioned together:

- **The heading** — a few verbatim lines plus the cycle's value proxy ("how we will know this works"). Pinned outside compaction, re-injected at every turn, injected by the kernel into every child node's context. The proxy is **visible to the agents**: it is their work target — hiding it would divert them. The Goodhart risk is accepted: the measurement remains invisible, and the proxy↔intention gap is read by the human.
- **The letter** — the rich text of the negotiation (the why, the intentions, the context). Versioned with the heading, stored in the world, readable on demand by any node via its shell; never injected systematically (cost, cache, dilution).

Authority rule: **the current version is authoritative — not memory, not the last message.**

## 3. The crystallization

- The conversation is **free and pure**: no probe, no measurement, no hidden protocol.
- **Initiative**: both sides can open a revision — the human whenever they want, agent zero via a chat message (no dedicated format; the proposal is an observable event like any other).
- **Drafting**: agent zero drafts the version proposals (heading + proxy + letter) **in its chat response** — it holds no world-write tool; its reformulation reveals what it has understood of the heading.
- **Activation**: a version becomes active only upon **explicit ratification by the human** — the effective single-writer on the direction artifact: unintegrated writes carry conflicting implicit decisions (Cognition, "Don't Build Multi-Agents"). Ratification is the constitutive act of the object, not a barrier, and it has one command: `direct --path DIRECTION.md --file <abs-path>` commits the file authored the reserved `human` and materializes it; the pin then reads the latest human-authored commit touching the path. Ratifying text that already equals the current one is the unchanged case: no commit, the pin does not move.
- The **ratification event** is dated and immutable, and its home is the world (a local-log-only home would place the ground truth off the observation surface). It is the ground truth of the whole metrology: post-heading relaxation time, drift vs adaptation, event studies — each heading change is a timestamped ITS intervention.
- **Cadence**: free, with a recorded recommendation — rare headings, intervening only when viability demands it. Headings too close together make relaxation unmeasurable: detection bounds on short time series are severe (Boettiger & Hastings 2012, J. R. Soc. Interface).

## 4. The channel

The reply is channel-side: the human types in the `chat` session (or commits the batch twin, `direct --text/--file`), and one `{v: 0, at, uid: human, text}` record lands in `<home>/chat.v0.jsonl` under the kernel-owned chat lock. That log is the human↔overlay conversation — the human's words live there and nowhere else — and a reply makes **no world commit**: the society cannot read it. The ratification is the **one world commit** the human makes (`direct --path`), and the pin moves at every node's next turn boundary. The wake is the watcher pair: a human record's arrival is caught by the `ChatWatcher` (the reply path), and a gateway-addressed conversation record by the `ConversationWatcher`, whose broadcast also arms the pending notice that wakes a parked node — both trigger the overlay's cycle cross-process, so the chat is continuous and asynchronous without a channel priority, and the overlay can initiate — propose a revision, relay a signal coming from the nodes, ask for clarification. The chat log is a kernel-owned record of its own (the human's replies have no frontier event); the trajectory is read from the frontier journal and the world's history; the per-node local logs are cold-start artifacts no observer reads.

The human's acts, in one table:

| Act | Surface | What lands |
|---|---|---|
| reply | the interactive `chat` session — the primary surface; `direct --text/--file` is the batch twin | one `{v: 0, at, uid: human, text}` record in `<home>/chat.v0.jsonl` under `<home>/.es/chat.lock`; no world commit |
| ratify | `direct --path DIRECTION.md --file <abs>` | one world commit authored the reserved `human`; the pin moves at every node's next turn boundary |
| read | the same `chat` session (`--tail N` bounds the rendered history; `--json` is the one-shot read) — `--conversation` renders the raw nodes↔overlay stream read-only | the kernel-owned chat log, and the raw conversation stream beside it |

A reply is saved even when no overlay is running (the session says so; the next configured cycle digests it); the session's wait is bounded, and Ctrl-C aborts the wait, not the session.

## 5. Non-goals

No measurement of sycophancy at first; no gates or approvals in the chat; no imposed cadence or revision heartbeat; no direct human ↔ working-node channel. Current state: the thread filter makes the last one true — a node reads only its own thread with the gateway, and the human's words live in the kernel-owned chat log, outside the conversation.

## 6. Consequences for the bootstrap ([seed.md](seed.md))

Agent zero alone holds the human channel; the seed's framing names "the person speaking to you" as agent zero, not the human, and no node has a direct human channel. The native chat replaces the retired `speak` verb: the overlay converses in its own cycle's prose, and the human writes through `chat` or `direct`. The provisional v0 direction and its pinning stay as specified, and the first negotiation that retires v0 takes place between the human and agent zero; the human's act is `direct --path DIRECTION.md`.
