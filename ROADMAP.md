## The project in one sentence

A **perpetual** system of LLM agents that follows a **direction** (not a finite objective) co-negotiated by chat between a human and an agent zero, whose structure **emerges** (nothing organizational is coded), on a minimal async event-driven kernel with an append-only journal. Intended contribution: the unoccupied triangle *perpetual × emergent × co-negotiated direction*, with the measurement instrument that goes with it.

## Where we stand in the conceptual roadmap

1. ✅ **Vision refocus** — kernel + chat + direction, nothing else. P4/P5 outside the kernel (operating on itself live IS the concept; the mirror/fork belongs to Part III). No hardware constraint (cheap/smart models to test: see `docs/research/models-overview.md`).
2. ✅ **Monitoring = the core, before any software design.** Settled instrument: **3 sensors + 1 metronome** — (1) semantic trajectory via embeddings (E/E, temporal novelty, drift), (2) structure graph (RSI, hierarchy, March), (3) value registry promises→acts→effects (value proxy negotiated per cycle); metronome = versioned direction (labels adaptation vs drift). The catalogue of ~20 metrics = a diagnostic manual that can be recomputed after the fact. Feasibility proven, devil's advocate defeated (`docs/research/devils-advocate.md`).
3. ✅ **Two memories** (decision by Noé): the **journal** hooked at the level of LLM API calls (Langfuse-style — physical trace, "model-visible means logged", immutable, layer 1); the emergent **useful memory**, managed by the agents, which we do not touch (layer 3 — but its usage remains visible in the journal).
4. ✅ **The bootstrap (2026-09-14)** — see `docs/seed.md`. Hybrid design B+C from a competition of 4 approaches: kernel = recursive graph of Γ∞ nodes (Cordis, custody ≠ authority); seed = 5 instincts + Finitude (the Hole alone — budget invisible to the agent, hard limit upstream on the API key, decision by Noé) + computed hole; **raw** tools (persistent shell, web_search/fetch, `étendre` (extend) = the single Cordis gate); **no approval guardrail** and **no provided memory** (decisions by Noé: observe free evolution; the agent, made self-aware of its machine, builds its own memory/context management); provisional-expiring direction v0; `spawn` not mounted, discoverable by introspection (Q1 slice); 3 falsification instruments (genesis adjacency, org/runtime isomorphism, organ usage graph).
5. ✅ **Chat & direction (2026-09-14)** — see `docs/direction.md`. Three physical roles: human (source) ↔ **agent zero = translator co-orchestrator** (intention ↔ heading, in both directions; does not work) ↔ standard nodes (never any direct human contact). **Double artifact**: pinned verbatim heading (with the cycle's value proxy, visible) + versioned rich letter (readable on demand). Crystallization: agent zero drafts, **the human ratifies** (single-writer); initiative on both sides; dated ratification event = ground truth for metrology. No measurement of sycophancy for now. Amends the bootstrap: `parler` (speak) = the channel to the custody parent, not a direct human channel.
6. ✅ **Kernel design (2026-09-14, evening)** — see `docs/kernel.md`. Settled behaviour: non-blocking async (no "waiting for the human" state), free loop + explicit waiting + wake budget, re-alignment without interruption (propagation = relaxation measurement), heading injected everywhere by the kernel + meaning in cascade through the org, agent zero = root node subject to the physics. **Stack: TypeScript / Node 24 LTS + `cordis@4.0.0-rc.10` pinned** (core only, without loader; gate wrapped; Packages in `node:vm` + restricted facade; reimplementation spike as a fallback). Journal: canonical per-node JSONL-zstd + RFC 8785 hash chain + claim-check + disposable SQLite index + deterministic replay for free. Cache-aware assembler (byte-stable prefix, **identical tool offer for all nodes — mitigation at the gate, not at the offer**); compaction = dsh protocol + naive policy. Sandbox: **Landlock** (verified on the machine: bwrap broken, Landlock ABI 8 OK without root — the API key becomes physically unreadable by the agent); node-pty PTY (does not survive restart — accepted); git commit driven by the kernel on every `exécuter` (execute) (`.git` read-only, workspace ≠ $HOME). Escalating kill switch (5 s non-tunable backstop). Suggested implementation order in §10 of the doc.
7. ⬜ Next: **implementation plan for checkpoint C1** (minimal kernel + agent zero + chat + a readable projection of the journal — criterion: we can see everything the agent does, and we can talk to it). Then a monitoring/cockpit session (3 sensors + metronome).

## Framing reminders (unchanged)

- No code before the design is validated (brainstorming → spec → plan).
- Golden rules: no organizational structure coded; metrics invisible to the agents (anti-Goodhart); fidelity measured on acts, never on declarations; the journal is the only truth, everything else is projection.
- Revised checkpoints: **C1** kernel + agent zero + chat + readable journal → **C2** agent zero hot-extends the system on its own initiative and survives a restart → **C3** spawn + direction: coherent trajectory where the solo drifts.
- Noé's role: intuition and vision. Kimi's role: verify feasibility, source, challenge, record.
- Everything is versioned in git — the commit history is the project's chronicle for the future paper.
